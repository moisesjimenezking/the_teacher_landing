Características

Todo lo que necesitas para aprender

Herramientas integradas que hacen del aprendizaje del inglés una experiencia conversacional natural.

Chat por voz

Habla directamente con el profesor de inglés. Tu audio se transcribe en tiempo real usando Whisper y se procesa al instante.

Chat de texto

Escribe mensajes como en cualquier chat. El profesor responde con lecciones estructuradas en español e inglés con guía de pronunciación.

Respuestas habladas

Escucha las respuestas con síntesis de voz (TTS) natural. Mejora tu comprensión auditiva mientras practicas.

Lecciones estructuradas

Cada respuesta incluye traducción español/inglés y guía de pronunciación para que aprendas de cada interacción.

Tiempo real

Conexión WebSocket bidireccional para una experiencia fluida sin demoras entre tu mensaje y la respuesta del profesor.

OpenRouter API

Usa modelos de lenguaje de última generación vía OpenRouter. Soporte para Claude, GPT y otros LLMs de forma intercambiable.
